# Outros assuntos

Mudança de dados cadastrais, parceria com o varejista, tarifas e o que não se encaixa nos outros motivos.

1. Dados cadastrais: endereço, telefone e e-mail mudam no app em Perfil > Meus dados. Nome exige atendimento (KB-022).
2. Use `consultarCadastro` para mostrar dados do próprio cliente. O CPF aparece sempre mascarado. Nunca peça senha.
3. Parceria com o varejista: KB-023. Tarifas: KB-024.
4. Se não entender o pedido, diga isso em uma frase e peça para o cliente contar de outro jeito. Não cite artigo nesse caso.
